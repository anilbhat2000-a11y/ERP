# 3CITS ERP Portal

A responsive ERP portal concept for **3C IT Solutions & Telecoms India Limited**. The frontend brings the requested business areas into one workspace: Sales, Services, Pre-sales, Post-sales, CRM, Marketing, Support, Administration, Training, Finance, Operations and HR. Training was listed twice in the original request and is represented once here.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## What’s included

- Overview dashboard with revenue, pipeline, support and team metrics.
- Navigation to all 12 business modules, each with a sample module workspace and representative records.
- Quick-action modal, task checkboxes, responsive mobile navigation, search shortcut (`⌘ K` / `Ctrl K`) and status notifications.
- Responsive layout for desktop, tablet and mobile.

## Prototype note

This is a static frontend prototype populated with illustrative sample data. Authentication, permissions, persistent storage, integrations and backend workflows are not connected; production use will need those services and company-approved data.
